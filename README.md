# AGI v7.0 — Нейробиологическая архитектура искусственного сознания

[![License: Proprietary](https://img.shields.io/badge/License-Proprietary-red.svg)](LICENSE)

## Описание

AGI v7.0 — это первая в мире полностью интегрированная нейробиологическая архитектура искусственного общего интеллекта, включающая:

- 🧠 **14+ структур мозга**: таламус, базальные ганглии, мозжечок, гиппокамп, префронтальная кора, лимбика, мост, средний мозг, чёрная субстанция и др.
- 💭 **Сознательный поток**: внутренний монолог с самоосознанием, метакогницией и осознанием действия
- 🎯 **Система автономных желаний**: 8 конкурирующих целей с нейронной динамикой
- ❤️ **Эмоциональная память**: дофаминовое подкрепление, эмоциональные следы, забывание
- 🔄 **System 1 / System 2**: переключение с взаимным торможением
- 📊 **Адаптивное сжатие**: обучаемое в реальном времени сжатие сенсорных данных
- 🧬 **Мета-обучение и метакогниция**: самонаблюдение и рефлексия

## Архитектура

Подробное описание архитектуры, нейробиологических модулей и принципов работы — в файле [`ARCHITECTURE.md`](ARCHITECTURE.md).

### Ключевые механизмы

1. **Сознательный поток (ConsciousnessStream)**
   - Внутренний монолог с тегами источников
   - Самоосознание на основе состояния
   - Приоритизация мыслей

2. **Система желаний (DesireSystem)**
   - 8 конкурирующих нейронных полей
   - Входы: энергия, голод, усталость, любопытство, страх, социальная потребность
   - Усталость и нормализация (гомеостаз)

3. **Эмоциональная память (EmotionalMemory)**
   - Следы памяти с эмоциональной валентностью
   - Дофаминовое подкрепление
   - Экспоненциальное забывание

4. **Сенсоры и сжатие**
   - Визуальные, аудиальные, проприоцептивные данные
   - Адаптивное PCA-подобное сжатие
   - Обучение на потоке данных
