## Аннотация

AGI v7.0 — это первая полностью интегрированная нейробиологическая архитектура искусственного общего интеллекта, включающая:
- 14+ структур мозга (таламус, базальные ганглии, мозжечок, гиппокамп, префронтальная кора, лимбика, мост, средний мозг, чёрная субстанция и др.)
- Сознательный поток с внутренним монологом и самоосознанием
- Систему автономных желаний с нейронной динамикой (8 конкурирующих целей)
- Эмоциональную память с дофаминовой модуляцией
- System 1 / System 2 переключение с взаимным торможением
- Адаптивное сжатие сенсорных данных (обучаемое в реальном времени)
- Мета-обучение и метакогницию

Архитектура реализована на Python с использованием NumPy и не требует внешних библиотек для работы ядра.

## Ключевые механизмы

### 1. Сознательный поток (ConsciousnessStream)
- Внутренний монолог с тегами источников (`self_awareness`, `planning`, `metacognition`, `action_awareness`)
- Буфер мыслей с приоритизацией
- Самоосознание на основе состояния

### 2. Система желаний (DesireSystem)
- 8 нейронных полей с конкуренцией
- Входы: энергия, голод, усталость, любопытство, страх, социальная потребность
- Усталость и нормализация (гомеостаз)

### 3. Эмоциональная память (EmotionalMemory)
- Следы памяти с эмоциональной валентностью
- Дофаминовое подкрепление
- Экспоненциальное забывание

### 4. Сенсоры и сжатие
- Визуальные, аудиальные, проприоцептивные данные
- Адаптивное PCA-подобное сжатие
- Обучение на потоке данных

## Результаты тестирования

Агент демонстрирует:
- Внутренний монолог с самоосознанием
- Осознанное планирование действий
- Эмоциональную реакцию (любопытство, удивление)
- Переключение между System 1 и System 2

```

ACTION: left
MODE: mixed
EMOTIONS: {'curiosity': 0.3, 'surprise': 0.2}
THOUGHTS:
  - [self_awareness] Я просыпаюсь... Кто я? Где я?
  - [metacognition] Я думаю в режиме: 🧠 медленное мышление (сознание)
  - [planning] Я планирую: left. Уверенность: 0.52
  - [action_awareness] Я собираюсь сделать: left
```
